## 📖 О проекте

`apiNode` — это быстрый микросервис-агент, предназначенный для взаимодействия мастер-панелей (например, [SWS](https://github.com/iliy-git/SVS)) с удаленными VPN-серверами (нодами). 

Сервис решает главную проблему классических панелей: **клиенты добавляются, продлеваются и удаляются на лету через встроенный gRPC API ядра Xray**, исключая разрыв существующих VPN-соединений и перезапуски процессов.

---

## ✨ Ключевые возможности

* 🚀 **Zero-Downtime:** Никаких перезагрузок Xray при операциях с клиентами. Соединения пользователей не рвутся.
* ⚡ **Высокая скорость:** Применение настроек клиента за 10–15 миллисекунд прямо в память ядра.
* 🛡 **Безопасность:** Доступ по HTTPS (TLS 1.2 / 1.3), проверка авторизации через заголовок `X-API-KEY`.
* 💾 **Резервное копирование:** Выгрузка консистентных бэкапов базы данных SQLite (`.db`) и структурированного JSON по запросу из мастер-панели.
* 💻 **Удобный CLI:** Интерактивное консольное меню `apinode` для настройки порта, ключей, логов и бэкапов (по аналогии с `x-ui`).
* 🔗 **Автогенерация ссылок:** Автоматическое формирование готовых конфигураций `vless://` (включая Reality, Vision, gRPC, WebSocket), `hysteria2://` и др.
* 🔄 **Отказоустойчивость:** Автоматическая синхронизация клиентов с ядром Xray при старте и восстановлении из бэкапа.

## 🚀 Быстрая установка (в одну команду)

Подключитесь к серверу по SSH (`root`) и выполните команду:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/iliy-git/apiNode/main/install.sh)
```

Скрипт автоматически:
1. Предложит выбрать порт (по умолчанию `11223`).
2. Установит Docker (если не установлен).
3. Создаст симлинк бинарника Xray для работы с gRPC API.
4. Сгенерирует SSL-сертификаты.
5. Откроет порт в файрволе (`UFW` / `iptables` / `firewalld`).
6. Запустит контейнеры и сгенерирует API-ключ.
7. Установит консольную утилиту `apinode`.

## 🛠 Консольное управление (`apinode`)

Для вызова интерактивного меню управления введите в терминале:

```bash
apinode
```

### Быстрые команды CLI:
* `apinode status` — Показать текущий IP, порт, ключ и статус работы
* `apinode backup` — Создать локальный консистентный бэкап базы данных
* `apinode port [порт]` — Изменить порт API (автоматически обновит Nginx и файрвол)
* `apinode key show` — Показать текущий API-ключ
* `apinode key gen` — Сгенерировать новый случайный ключ
* `apinode sync` — Синхронизировать всех клиентов из базы в память Xray
* `apinode logs` — Просмотр логов работы API в реальном времени
* `apinode restart` — Перезапустить контейнеры сервиса
* `apinode update` — Обновить apiNode до последнего релиза из репозитория

## 📡 Спецификация API (Endpoints)

Все запросы требуют заголовок: `X-API-KEY: <ваш_ключ>`.

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/ping` | Проверка связи и валидности API-ключа |
| `GET` | `/inbounds` | Список всех входящих подключений (inbounds) на ноде |
| `GET` | `/clients` (или `/stats`) | Список всех клиентов с объемом трафика (`up`/`down`), статусом и ссылками |
| `GET` | `/email?email=user@domain` | Статистика и ссылка конкретного клиента |
| `POST` | `/client/add` | Мгновенное добавление клиента в память ядра + в базу (возвращает готовую ссылку `link`) |
| `POST` | `/client/delete` | Мгновенное удаление клиента из ядра Xray и базы |
| `POST` | `/email/extend` | Продление подписки клиента (в днях) |
| `POST` | `/xray/sync` | Прогрев: принудительная синхронизация всех активных клиентов в память Xray |
| `GET` | `/backup` | **Скачать резервную копию базы данных** в виде файла `.db` |
| `GET` | `/backup?format=json` | **Экспорт бэкапа в формате JSON** (все inbounds, клиенты, трафик и settings) |
| `POST` | `/backup/restore` | **Восстановление базы данных** из файла `.db` (multipart) или JSON payload |

## 💾 Как мастер-панель запрашивает бэкап

### Скачивание файла базы данных (.db):
```php
$response = Http::withHeaders(['X-API-KEY' => $apiKey])
    ->withoutVerifying()
    ->get("https://{$nodeIp}:11223/backup");

file_put_contents("backup-{$nodeIp}.db", $response->body());
```

### Запрос бэкапа в формате JSON:
```php
$response = Http::withHeaders(['X-API-KEY' => $apiKey])
    ->withoutVerifying()
    ->get("https://{$nodeIp}:11223/backup", ['format' => 'json']);

$backupData = $response->json();
// $backupData['data']['inbounds'], $backupData['data']['clients'], $backupData['data']['settings']
```

## 🏗 Архитектура

```text
[Клиент / Мастер-панель]
           │
           │ HTTPS (порт 11223 или кастомный)
           ▼
     [vpn_nginx_ssl]  (TLS termination, проверка сертификатов)
           │
           │ FastCGI (127.0.0.1:9000)
           ▼
    [x-ui-api-mini]   (PHP 8.3 FPM)
      ├── SQLite DB   (Хранение настроек, клиентов и инбаундов)
      ├── BackupService (VACUUM INTO снапшоты, JSON экспорт/импорт)
      └── XrayService (gRPC CLI вызовы: xray api adu / rmu / statsquery)
           │
           │ gRPC (127.0.0.1:62789)
           ▼
     [Xray-core]      (Сетевой трафик, 0 downtime, счетчики байт)
```
